## Por qué

No escribas "quiero mejorar mi inglés". Escribe la **situación concreta** que quieres superar:

- una entrevista técnica de 30 minutos
- una reunión semanal con un equipo distribuido
- leer documentación sin traductor
- un examen con fecha

Esto es lo que más cambia el currículo. "Mejorar inglés" lleva a estudiar de todo un poco; una
situación concreta ordena las prioridades sola.

## Interferencias de tu idioma nativo

Los errores que comete alguien que habla tu lengua materna. Son los más persistentes porque suenan
correctos en tu cabeza.

| Error | Correcto | Por qué se produce |
|---|---|---|
| | | |

<details>
<summary>Ejemplo para hispanohablantes</summary>

| Error | Correcto | Nota |
|---|---|---|
| "Actually I work at…" | "Currently I work at…" | *Actually* = en realidad |
| "I assisted to the meeting" | "I attended the meeting" | *Assist* = ayudar |
| "We realized the migration" | "We carried out the migration" | *Realize* = darse cuenta |
| "I'm agree" | "I agree" | *Agree* es verbo |
| "People is" | "People are" | |
| "Since 3 years" | "For 3 years" | *since* = punto, *for* = duración |

**Vocal epentética ante grupos con s-**: *"eschool"*, *"estack"*. Muy audible para un oído nativo y
corregible de forma consciente.
</details>
